Practical tuicr Fluency

A short course for using `tuicr` as a fast terminal-native code review surface and as a bridge between human review and coding agents.

Foundations
  • 01 Open the Right Review Pick the right command for working tree changes, commit ranges, PRs, MRs, or stdout export. ~5 min
  • 02 Navigate Without Getting Lost Build a small movement vocabulary: scan, jump between files, jump between hunks, search, and focus panels. ~6 min
  • 03 Place Review Comments Choose line, range, file, or review-level comments and match feedback to the right target. ~7 min
Workflow
  • 04 Finish and Export Mark progress, copy structured markdown, pipe output, or submit the review to a forge. ~6 min
  • 05 Agent Review Loop Use `tuicr review` commands so an agent can read human comments or add labeled findings. ~8 min
Reference
  • -- tuicr Field Guide Quick lookup for launch commands, movement keys, comment targets, export, and review CLI commands. ref
