# tuicr Resources

## Knowledge

- [agavra/tuicr README](https://github.com/agavra/tuicr)
  Primary overview of what `tuicr` does, install options, quick-start commands, export targets, configuration, and first-session keybindings. Use for: course grounding and first-use workflows.
- [tuicr review workflow skill](https://raw.githubusercontent.com/agavra/tuicr/main/skills/tuicr/SKILL.md)
  Agent-facing workflow for attaching to active sessions, reading user comments, adding agent-authored comments, and launching panes. Use for: lessons about agent collaboration.
- [tuicr Review Session CLI docs](https://raw.githubusercontent.com/agavra/tuicr/main/docs/REVIEW_CLI.md)
  Primary source for `tuicr review list`, `comments`, and `add`, including JSON output shapes and session selectors. Use for: scripting and agent-integration lessons.
- [tuicr Keybindings docs](https://raw.githubusercontent.com/agavra/tuicr/main/docs/KEYBINDINGS.md)
  Full reference for navigation, file tree filtering, panel focus, commenting, visual mode, and command mode. Use for: retrieval drills and quick reference.
- [tuicr Configuration docs](https://raw.githubusercontent.com/agavra/tuicr/main/docs/CONFIG.md)
  Primary source for config file location, themes, diff view, whitespace handling, mouse support, leader key, comment types, and ignore rules. Use for: workflow customization.
- [GitHub Docs: Pull request reviews](https://docs.github.com/en/pull-requests/reference/pull-request-reviews)
  Explains review outcomes: comment, approve, and request changes. Use for: mapping local `tuicr` review work to GitHub review decisions.
- [GitHub Docs: Commenting on a pull request](https://docs.github.com/en/pull-requests/how-tos/review-pull-requests/commenting-on-a-pull-request)
  Explains line, file, range, single-comment, and batched-review comments. Use for: review etiquette and comment-target choices.

## Wisdom (Communities)

- [tuicr GitHub issues](https://github.com/agavra/tuicr/issues)
  Best place to see real user problems, feature requests, and edge cases. Use for: learning limitations and troubleshooting patterns.
- [tuicr GitHub discussions via pull requests](https://github.com/agavra/tuicr/pulls)
  Real examples of how the project itself is reviewed. Use for: observing practical review comments and project norms.
