Glossary

Terminology for the fullstack-agent study. Updated each lesson.

Project and components

TermMeaning
fullstack-agentJared Rhodenizer's repo. A Claude-Code-only installer wizard that assembles four separate personal-AI repos into one desktop assistant. Not an agent framework.
the stackThe four assembled pieces together: memory, voice, face, hands. "Full stack" means the agent has a stack, not that it builds full-stack code.
ai-memory-vault"The mind." Plain-text (Markdown/Obsidian) file-based persistent memory the agent reads and writes.
backtalk"The mouth." Push-to-talk (or open-mic) voice input/output. Also owns the config that wires pieces together.
ai-visualizer"The face." Full-screen browser visualizer that reacts to conversation state (idle, listen, think, speak).
barehands"The hands." Optional webcam gesture control to move notes and images on screen. No headset.

Architecture and patterns

TermMeaning
installer-as-specThe install logic is a prose file (fullstack-agent.md) executed by the LLM, not compiled code. The wizard is a document.
phased wizardThe install runs in ordered phases: find-home, menu, interview, install, wire, hello, hand-over. Answers collected once, executed later.
the home folderThe parent directory containing the toolbox repo. The agent "lives" here; Claude Code must open here for the agent to be itself.
adopt, never destroyCore principle: pre-existing user state (vaults, identities, hand-built pieces) is found and kept, never deleted, overwritten, or moved. Replacements retire the old thing in place.
config-path wiringComponents connect only by writing each other's file paths into JSON config. No shared library, no API. Loose coupling by filesystem.
status-file busInter-component communication via a shared directory of small state files: voice writes status notes, face reads them. A filesystem message bus.
agent-as-mechanicEach component ships a TROUBLESHOOTING.md written for the agent to read. When something breaks, the agent fixes itself; the user never debugs.
the mechanic sectionA block appended to the home CLAUDE.md instructing the agent that repairing the stack is its own job.
present verbWhen asked to SEE something, the agent puts it on the visualizer ("glass") instead of replying in text.

Evaluation lenses (external)

TermMeaning
workflow vs. agentAnthropic's distinction: workflows follow predefined code paths; agents dynamically direct their own process. A lens to classify what fullstack-agent's pieces are.
12-factor agentsA set of design principles for durable agent systems; a checklist to judge this stack against.
