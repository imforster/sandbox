Resources

Trusted sources for the Kiro CLI v3 course. Lessons draw from these, not from memory. Source of truth: RESOURCES.md.

Overview and migration

  • Upgrade from CLI 2.x (What's new in V3)

    Feature list, v3 vs v2 parity table, breaking changes. Use for: the overall map.

  • Migration guide

    Seven steps: /upgrade-agent, hook renames, permissions.yaml, use_aws removal. Use for: converting agents, hooks, trust settings.

  • Blog: Kiro CLI V3 is rolling out as the default

    Rationale and highlights: cloud sessions, memories, spec, tangent, /sessions, workflows, global hooks, nested AGENTS.md. Use for: the why.

  • CLI changelog

    Release-by-release changes, such as Approve for me. Use for: anything newer than 3.0.

Permissions and hooks

  • Permissions

    Capabilities, effects, scopes, deny-overrides, presets, Approve for me, workspace trust.

  • Hooks migration

    v2 object hooks to v3 arrays or standalone files; trigger renames; global hooks.

  • Hooks, Hook types, Hook actions

    Schema, triggers, exit codes. The actions page says any non-zero exit blocks PreToolUse; verify exit 2 vs 1 locally (lesson 2).

Working differently

  • Tangent and Checkpoints and rewind

    Tangent commands and merge; rewind vs checkpoints (checkpoints are IDE or experimental v2 only).

  • Specs

    Spec types, the three files, task waves. No official CLI-specific page found for /spec new.

  • Workflows and Author workflows

    Concepts, recipe format, safety and permissions.
