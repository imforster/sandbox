Hook file

{ "version": "v1",
  "hooks": [{
    "name": "x", "trigger": "PreToolUse", "matcher": "shell",
    "action": { "type": "command", "command": "./guard.sh" },
    "timeout": 60, "enabled": true }] }
PlaceScope
Agent hooks arrayOne agent
.kiro/hooks/*.jsonWorkspace
~/.kiro/hooks/*.jsonGlobal

Triggers: SessionStart, UserPromptSubmit (CLI cannot block), PreToolUse (can block), PostToolUse, Stop, SessionEnd, PreCompact, PostCompact, PostFileCreate, PostFileSave, PostFileDelete, PreTaskExec, PostTaskExec. v2 camelCase names are accepted aliases. Matchers: read write shell web spec, @builtin @mcp @server @server/tool, wildcard, or regex. Source: Hook types.
