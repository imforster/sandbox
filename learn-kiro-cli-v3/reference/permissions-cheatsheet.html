Permissions cheat sheet

Kiro CLI v3 capability rules. Source: kiro.dev/docs/permissions.

Rule anatomy

rules:
  - capability: shell        # what kind of operation
    match: ["npm *"]         # glob(s)
    exclude: ["npm publish*"]# must NOT match
    effect: allow            # deny | ask | allow | evaluate

Where rules live

ScopeLocation
user~/.kiro/settings/permissions.yaml
workspace~/.kiro/workspace-roots/<hash>/permissions.yaml (outside the repo)
agentpermissions field in the agent profile
sessionIn memory (from approval prompts)
Resolution

deny > ask > allow > evaluate. No scope precedence; most restrictive wins.

v2 to v3 map
