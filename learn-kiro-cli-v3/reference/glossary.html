Glossary

Terms used in the Kiro CLI v3 for v2 Users course.

A

Approve for me
Permission mode where a trust classifier judges actions that no rule settles: approve if safe, block if unsafe, ask if unsure. Implemented as the evaluate effect.

C

Capability
The class of operation a permission rule governs, such as fs_read, fs_write, shell or mcp.

D

Deny-overrides
The resolution order deny > ask > allow > evaluate, applied across all scopes with no scope precedence.

E

Effect
What a matching rule does: deny, ask, allow or evaluate.

G

Glob
The pattern syntax in v3 match and exclude. Replaces v2 regex; shell patterns support only *.
Global hook
A hook file in ~/.kiro/hooks/ that fires in every workspace, alongside workspace hooks.

H

Harness
The agent engine that owns tools, context, permissions and model calls. V3 uses the same harness as Kiro IDE and Web; v2 is the older CLI harness.
Hook
An automation bound to a trigger, with an optional matcher and an action that is a shell command or an agent prompt.

M

Matcher
The filter on a hook: a tool selector or regex for tool triggers, a path regex for file triggers.

P

permissions.yaml
The file of capability rules. User scope: ~/.kiro/settings/permissions.yaml; workspace scope lives under ~/.kiro/workspace-roots/.

R

Recipe
A JSON or YAML file describing a workflow graph, stored in .kiro/workflows/ or ~/.kiro/workflows/.
Rewind
/rewind forks the conversation at an earlier turn into a new session. It never changes files.
Rule
One entry in permissions.yaml or an agent's permissions: a capability, optional match and exclude globs, and an effect.

S

Scope
Where a rule comes from: Kiro (hardcoded), administration, user, workspace, agent or session.
Spec
Three files (requirements or bugfix, design, tasks) that turn an idea into tracked implementation work. Started with /spec new.

T

Tangent
A named, nestable side conversation that inherits context and stays isolated until you /tangent merge.
Task wave
A group of spec tasks whose dependencies are all met, run concurrently; waves run in order.
Trigger
The event that fires a hook, such as PreToolUse or PostFileSave. Written in PascalCase in v3.

U

/upgrade-agent
V3 command that converts v2 agent configs to the universal format, backs up originals, and reports warnings via /upgrade-agent diagnostics.

W

Workflow
A background graph of agent steps, loops and parallel branches, each step in its own fresh session.
