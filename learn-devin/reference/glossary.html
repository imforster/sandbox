Glossary

Key terms for Devin.ai control modes, onboarding, review, and multi-agent orchestration. Grounded in the official Devin docs.

A
AGENTS.md
A repo-root instruction file — a "README for agents." Devin reads it before coding. Covers setup commands, code style, testing, structure, and workflow.
Ask
A read-only mode that answers questions about the codebase with cited results and makes no changes. Trigger: /ask.
Auto-Fix
A Devin Review setting where Devin proposes fixes for detected bugs and responds to review comments and CI failures, iterating a PR toward merge-ready quality.
B
Bug Catcher
The Devin Review analyzer that flags likely bugs by severity and surfaces security findings with CWE classification.
Bypass Permissions
The most permissive mode: auto-approves all tool calls — writes and shell — with no isolation. Never overrides admin org rules. Trigger: /bypass (confirm the name with /help).
C
Code
The default write mode: writes code and auto-accepts edits in the workspace while still prompting for shell commands. The everyday mode for executing a scoped task. Trigger: /code.
D
Devin CLI
A local command-line coding agent with cloud integration. Install: curl -fsSL https://cli.devin.ai/install.sh | bash.
Devin Desktop
The full AI-powered IDE surface, including Cascade, autocomplete, chat, and command.
Devin Review
An automated PR review platform with organized diffs, a Bug Catcher, and security scanning. Trigger on a PR by commenting /devin review.
K
Knowledge
Persistent context recalled automatically across sessions — coding standards, common fixes, internal tooling. Pin to a repo or apply globally.
M
@ mention
An inline context reference in a prompt: files, repos, macros, playbooks, skills, secrets, or sessions.
Mode
The single setting that governs how much Devin does before asking. Five choices, least to most autonomous: Ask, Plan, Code, Smart, Bypass Permissions. Cycle with Shift+Tab or set with a slash command.
P
Plan
A read-only mode that scopes and plans a task into a context-rich prompt, without making code changes. Trigger: /plan.
Playbook
A reusable, shareable prompt template capturing a step-by-step procedure for a recurring task, unlike Knowledge which stores broad context.
R
Repo indexing
An onboarding step that lets Devin understand and search your codebase before it works. Do this before your first real session.
REPL
The default interactive terminal interface for a CLI session — chat back and forth while observing Devin's actions.
REVIEW.md
A dedicated instruction file that customizes how Devin Review analyzes a project — areas needing scrutiny, anti-patterns, and files to ignore.
S
Session
One unit of work with Devin. Resumable with devin -c (continue) or devin -r (pick recent).
Session Insights
Post-session analysis — a timeline of what happened, actionable feedback, and an improved prompt for similar future tasks.
Single-turn mode
Running devin -p "prompt" to print one response and exit. Ideal for scripts and automation.
Smart
A write mode like Code, plus a fast model that auto-runs other actions it judges clearly safe, while always prompting for high-risk operations. Trigger: /smart.
Subagent
An independent worker a session spawns that shares tools and codebase but runs in its own conversation. Profiles: explore (read-only, cheap) and general (write-capable, parent's model).
Success criteria
The observable checks that define "done" for a task — a test passing, an endpoint returning 200, a rendered page.
T
3-Hour Rule
A rule of thumb: if a task would take you three hours or less, Devin can most likely do it. Break bigger work into parallel sessions.
