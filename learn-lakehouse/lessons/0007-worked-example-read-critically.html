A worked example, read critically

Lesson 7 of 8. Time: 10 minutes. Tangible win: trace one Iceberg table serving BI and ML, and name two claims to test.

The paper closes with a small build. Trace it, then decide what it proves. Source: Sections 7 and 8.

The pipeline

flowchart TD
    P["Parquet files on Amazon S3"] --> I["Apache Iceberg table format"]
    N["Project Nessie catalog"] --- I
    I --> S["Dremio Sonar SQL engine"]
    S --> T["Tableau dashboard"]
    I --> K["Apache Spark with scikit-learn"]
    K --> M["Churn model"]

The authors create an Iceberg table with one SQL statement, build a dashboard on it, then train a churn model from the same table, with no export step in between.

What it shows and what it does not

ShowsDoes not show
One table can feed BI and MLQuery speed against a warehouse
No export pipeline in this flowCost comparison with any warehouse
Open formats work across enginesBehavior at large scale or with many users
Vendor caveat

The authors work for Dremio, and the example uses Dremio Sonar. The paper itself says large-scale implementations vary in complexity and tool stack. Treat the example as a demonstration, not a benchmark.
