Jev in the Harness

Time: 8 minutes. Tangible win: you can name the two harness roles Jev plays — tool-call gating and model routing — and read the LangChain middleware that wires each.

This is where the mission lands, Ian. You can spot a Jev job (L1), shape it (L2), gate it (L3), and compose it (L4). Now you place Jev inside an agent harness — the loop where an LLM picks tools and acts — and use it to make that loop cheaper and safer.

Primary source Building a Harness with Jev — LangChain (Runkle & Lovell, ~5 min). Shows TypeSafeClassifier, ModelRouterMiddleware, and AutoModeMiddleware in real code.

Role 1: model routing

Not every request needs your best model. A lookup can go to a small, cheap model; an architecture question needs a powerful one. Jev classifies the incoming request and picks the model before the loop spends a dime on reasoning.

from langchain.agents import create_agent
from langchain_typesafe.experimental.middleware import (
    ModelChoice, ModelRouterMiddleware,
)

router = ModelRouterMiddleware(
    choices={
        "fast": ModelChoice(
            model="openai:luna",
            criteria="Direct lookups, extraction, localized changes.",
        ),
        "powerful": ModelChoice(
            model="openai:sol",
            criteria="Architecture and high-stakes decisions.",
        ),
    },
    instructions="Choose the least costly model that can complete the task.",
)

agent = create_agent("openai:gpt-5.6-luna", middleware=[router])

Under the hood this is a Jev Choice over your model options. The chosen model, its probabilities, and confidence stay in the agent state, so you can log or override the routing decision.

Role 2: tool-call gating (Auto Mode)

Agents can be talked into dangerous actions — a poisoned web page, a bad instruction, a misread. Closed harnesses (Claude Code, Codex, Cursor) have long classified risky actions before running them. A cheap classifier lets any agent do the same.

from langchain.agents import create_agent
from langchain_typesafe.experimental.middleware import AutoModeMiddleware

guardrail = AutoModeMiddleware(tools=["bash"])

agent = create_agent("openai:gpt-5.6-luna", middleware=[guardrail])

Before the bash tool executes, Jev evaluates the proposed call and blocks it if it looks risky. This is a Noul ("is this dangerous?") gated on confidence — exactly the pattern from Lesson 3, now sitting on the tool boundary.

One model, two jobs

Jev is not a drop-in LLM replacement — it generates no text. The harness pattern is a division of labor: the LLM does open-ended reasoning and generation; Jev makes the fast structured decisions along the way — which model, which route, is this safe.

A gate is not a guarantee

Auto Mode reduces risk; it doesn't eliminate it. It's a calibrated classifier, so tune its confidence threshold to your blast radius and keep hard limits (sandboxing, allow-lists, human approval) for genuinely destructive actions. Trust the gate proportionally to what a false negative would cost.

Retrieval check

In a Jev-powered harness, which job stays with the LLM rather than moving to Jev?

Right. Generating code is open-ended text — an LLM job. Routing and risk-gating are structured decisions, which is exactly what Jev handles cheaply and fast.
