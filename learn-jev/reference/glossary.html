Glossary

Canonical language for the Jev / System One course. All lessons use these terms.

C

Calibrated Confidence
A model's honest estimate of how likely its own answer is correct, where higher confidence reliably means higher accuracy. Lets code set act-vs-escalate thresholds. Avoid: certainty, sureness.
Choice (question type)
A Jev question that picks one option from a fixed set, returning a probability per option plus an overall confidence. Avoid: classification, category pick.
Confidence
How sure Jev is about a whole answer distribution (distinct from the probability of any one option). The number you branch on when deciding to act, review, or escalate. Avoid: certainty, accuracy.

H

Harness
The loop and surrounding code in which an LLM picks tools and acts. Jev sits inside a harness to route requests and gate risky tool calls cheaply. Avoid: agent framework, wrapper.

J

Jev
TypeSafe AI's first public System One model. Named after William Stanley Jevons — cheaper intelligence is expected to increase demand for it. Avoid: the Jev LLM, the Jev chatbot.

M

Model Routing
Using a Jev Choice to pick which LLM handles a request — cheap model for lookups, powerful model for hard tasks — before the loop spends on reasoning. Avoid: model switching, dispatch.

N

Noul (question type)
A Jev question answering a yes-or-no statement, returning the probability that the statement is true. Avoid: boolean, yes/no flag.

P

Probability
How likely a given answer is (e.g. billing 0.84) — which option leads. Distinct from confidence, which is how sure Jev is about the whole distribution. Avoid: score, likelihood.

R

RLCD (Reinforcement Learning for Calibrated Decisions)
The training method behind System One models, optimizing for calibrated typed decisions rather than human-preferred text (the goal of RLHF). Avoid: RLHF variant.

S

Score (question type)
A Jev question rating an input against ordered levels (e.g. low, medium, high), returning a continuous score, the distribution, and a confidence. Avoid: rating, grade.
State
The context you send Jev to evaluate — text, structured data, or messages. The "unstructured input" half of a System One call. Avoid: prompt, input.
System One Model
A class of AI model that evaluates a state and returns typed answers with probabilities, for software to act on directly — versus an LLM that generates text. Named after Kahneman's fast, intuitive System 1. Avoid: small LLM, classifier LLM.

T

Tool-Call Gating (Auto Mode)
Using a Jev Noul to judge whether a proposed tool call is dangerous, and blocking it before it runs. Sits on the tool boundary in a harness. Avoid: guardrail, safety filter.
Type-safe
Jev's outputs match a schema defined in advance and never contain type errors, so code can use them directly without parsing or validation. Avoid: structured, validated.

W

Workflow
Several independent, decomposed Jev questions asked in one call, combined by ordinary code into a final branch. The reliable shape for real automation. Avoid: pipeline, chain.
