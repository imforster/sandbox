Slice and Run Your First Print

Lesson 4 · Learn 3D Printing · ~10 minutes
Primary source

Prusa's printer handbooks cover the full path from setup and calibration through slicing, printing, and troubleshooting. Even if you buy another brand, the sequence is useful.

Slicing is translation. A model file says what shape you want. The slicer decides how the printer will build it: layer height, walls, infill, supports, temperature, speed, and movement path.

model file -> slicer profile -> preview layers -> printer file -> first layer -> finished part -> inspection

Your first-print loop

  1. Use the manufacturer setup guide and a known-good PLA profile.
  2. Choose a small model with many successful user photos, not a complicated trophy print.
  3. Slice with default settings and preview the layers before printing.
  4. Watch the first layer. Stop early if it is not sticking or looks like loose spaghetti.
  5. After printing, inspect bottom surface, walls, top surface, and dimensions.
  6. Change one variable at a time on the next attempt.

What to inspect

SymptomLikely areaBeginner response
Part detachesBed adhesionClean plate, check first layer, avoid drafts
StringingTemperature or retractionUse known material profile before tuning
Blobby cornersSpeed or coolingPrint slower or use default profile
Wrong sizeModel, shrinkage, or calibrationMeasure, then adjust model tolerance
The beginner discipline

Do not tune ten settings after one failed print. First prove the printer works with a known-good model and default profile.

Check Your Understanding

What is the slicer's job?
  • Translate model to instructions
  • Invent a better model
  • Fix every print flaw
Correct. The slicer turns shape into printable toolpaths and settings.
Not quite. A slicer translates and configures the print; it does not replace modeling or diagnosis.

Do This Now

Find one small Printables model with user photos and write down: estimated print time, material, whether it needs supports, and what success should look like.
